# Почему нет версии для iPhone

Коротко: iOS не даёт сторонним приложениям ни доступа к номеру входящего звонка, ни права
отклонить его. Сценарий «сверить с контактами и сбросить» там не реализуем.

## Что есть в iOS

- **Call Directory extension** (с iOS 10). Приложение заранее отдаёт системе статический
  список номеров: блокировать или подписать. Логику «блокируй всё, чего нет в контактах»
  так не выразить — система блокирует только перечисленные номера. Список нужно
  поддерживать в актуальном состоянии, и он не может быть «всем, кроме моих контактов».
- **Live Caller ID Lookup** (с iOS 18). Расширение может запросить у вашего сервера
  сведения о звонящем приватным запросом. Это определитель номера с бэкендом и базой
  данных, а не локальный фильтр: нужен сервер, наполнение базы и её модерация.
- Аналога `CallScreeningService` — перехвата до первого гудка с решением «отклонить» —
  в iOS нет и не было.

## Чем это отличается от нашего приложения

«Стоп-звонки» принимают решение локально: есть номер в адресной книге — пропустить,
нет — сбросить. Всё считается на телефоне, ничего не уходит в сеть (кроме проверки
обновлений), и база спама не нужна.

Самый близкий iOS-аналог — Truecaller и Hiya: серверная база номеров и статический
список блокировки. Это другой продукт с другими затратами, и приватность «всё на
устройстве» в нём недостижима.

## Что делать пользователю iPhone

1. Настройки → Телефон → **«Тишина неизвестных»** (Silence Unknown Callers) — система
   не будит телефоном звонки с номеров, которых нет в контактах, но и не сбрасывает их:
   вызов уходит в журнал как пропущенный.
2. При желании — приложение-определитель со списком спама (CallKit), понимая, что оно
   работает по серверной базе, а не по вашим контактам.

## Итог

Версии для iPhone не будет: платформа не позволяет реализовать нашу модель. Если
Apple когда-нибудь откроет API для перехвата звонков с доступом к номеру — вернёмся
к этому вопросу.
