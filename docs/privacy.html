Политика конфиденциальности

Приложение «Стоп-звонки» (CallGuard) для Android. Обновлено 2 ноября 2026.

English version ↓
Коротко. Приложение работает на телефоне. В сеть оно выходит только чтобы спросить у GitHub номер последней версии. Оно не собирает, не хранит на серверах и не передаёт никому номера звонков, контакты и журнал.

Какие данные обрабатываются

  • Контакты. Приложение читает имена и номера из адресной книги, чтобы понять, есть ли звонящий в контактах. Список номеров хранится только в памяти процесса и обновляется раз в 5 минут. Он не записывается в файлы, не передаётся и не загружается в сеть.
  • Номер входящего звонка. Передаётся приложению системой через CallScreeningService и сохраняется в журнал только на устройстве.
  • Журнал и настройки. Хранятся в локальной базе SQLite и SharedPreferences на телефоне. Пользователь может очистить журнал в приложении или удалить все данные, удалив приложение.
  • Статистика. Считается локально из журнала, отдельной базы нет.

Разрешения и зачем они

  • READ_CONTACTS — сверка номера звонящего с адресной книгой.
  • INTERNET — только проверка номера последней версии на GitHub.
  • POST_NOTIFICATIONS — тихий индикатор «Фильтр включён» в шторке.
  • RECEIVE_BOOT_COMPLETED — возврат индикатора после перезагрузки телефона.

Разрешения на установку приложений и на доступ к журналу вызовов не запрашиваются.

Сеть

Единственный запрос — GET https://api.github.com/repos/garneva13/stop-calls/releases/latest: приложение узнаёт номер последней версии. Никаких данных о звонках, контактах и журнале в запросе нет. APK скачивается вручную из браузера: разрешения на установку пакетов у приложения нет.

Передача данных третьим лицам

Нет. Приложение не продаёт и не передаёт данные: у него нет для этого ни кода, ни сетевого разрешения.

Дети

Приложение не предназначено для детей и не собирает данные о них.

Изменения

Если политика изменится, новая версия будет опубликована на этой странице с датой обновления.

Контакты

Вопросы и сообщения об ошибках: github.com/garneva13/stop-calls/issues.

Privacy policy

CallGuard for Android. Last updated: 2 November 2026.

In short. The app runs on the phone. Its only network request asks GitHub for the latest version number. It does not collect, store on servers or share phone numbers, contacts or the journal with anyone.

What is processed

  • Contacts. Read to check whether the caller is in your address book. The index stays in memory, is refreshed every 5 minutes, is never written to disk and never leaves the device.
  • Incoming number. Delivered by Android through CallScreeningService and stored in the on-device journal.
  • Journal and settings. Stored locally in SQLite and SharedPreferences. You can clear the journal in the app or remove everything by uninstalling it.
  • Statistics. Computed locally from the journal; there is no separate database.

Permissions

  • READ_CONTACTS — compare the caller with the address book.
  • INTERNET — check the latest version number on GitHub only.
  • POST_NOTIFICATIONS — the silent “Filter is on” status notification.
  • RECEIVE_BOOT_COMPLETED — restore the indicator after a reboot.

No package installation and no call log access.

Network

One request: GET https://api.github.com/repos/garneva13/stop-calls/releases/latest to read the latest version number. No call, contact or journal data is included. The APK is downloaded manually from the browser; the app has no permission to install packages.

Third parties

None. The app does not sell or share data: it has neither the code nor the network permission for it.

Children

The app is not directed to children and collects no data about them.
